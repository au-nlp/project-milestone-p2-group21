\section{Datasets}
\subsection{SMOL}
SMOL\cite{caswell2025smolprofessionallytranslatedparallel} (Set of Maximal Leverage) is a high-quality translation corpus from English to more than a hundred low-resource languages. SMOL includes SMOLSent and SMOLDoc, which represent sentence-level and document-level translations is nicely accompanied by Gatitos\cite{jones-etal-2023-gatitos} which provides token-level translations across many of the same languages.
In this project specifically, we use the English-Cantonese portion of \textsc{Smol} and \textsc{Gatitos}, where there are translations on all three levels of data. For use in our experiments, we flatten the SMOLDoc dataset such that it consists of sentence pairs like SMOLSent, and combine the two datasets using a 80/10/10 split for training/validation/test. We make sure to not have any overlapping sentences between the splits, and that the same splits are used for all experiments.

\subsection{Monolingual Cantonese corpus by M. Dare, et. al}
In their work on unsupervised Mandarin-Cantonese machine translation, Dare et. al.\cite{dare2023unsupervisedmandarincantonesemachinetranslation} collected a large corpus of monolingual Cantonese sentences from various online sources. In total 912258 lines were collected by scraping and cleaning data from Wikipedia, Instagram, and a few other sites including a few corpusses compiled for previous academic work. Common for most sources that form the corpus is that the content is mostly user-generated text, which often includes non-standard spellings and colloquial language, which is typical for Cantonese as a language.
We use this corpus to train Cantonese token embeddings for the embedding transform experiment described in Section 3.
