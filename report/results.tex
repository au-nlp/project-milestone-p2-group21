\section{Results}
\subsection{Token replacement}
After performing token replacement and translating the resulting sentences with \textsc{MADLAD}, we calculate BLEURT scores. On average, the token replacement approach performs slightly worse than the baseline, with an average BLEURT score of $0.6704$ compared to the baseline's $0.6807$. We do however observe that the translation of many sentences improve significantly, both by BLEURT score and by our personally determined translation quality. At the same time, many sentences also see a significant drop in BLEURT score and translation quality. A few examples of this can be seen in the table \ref{table:tokenreplacementexample}.
To check whether the ratio of Cantonese characters in the source sentence has an effect on the performance of the token replacement approach, we bin the sentences by their ratio of replaced characters and plot violin plots of the BLEURT scores for each bin in figure \ref{fig:bleurt_token_replacement}. We see no real trend in the results, with both the baseline and token replacement approach performing similarly across all bins, although there is a slight tendency for the token replacement approach to perform better on sentences with a higher ratio of Cantonese characters.

\subsection{Embedding transform}
\label{results:embedding_transform}
We train the GloVe embeddings using Stanford's GloVe implementation\footnote{https://nlp.stanford.edu/projects/glove/} for $15$ epochs. We train the Word2Vec embeddings using Gensim's Word2Vec implementation\footnote{https://radimrehurek.com/gensim/models/word2vec.html} for $6$ epochs.

We train the embedding transformation matrix using stochastic gradient descent with a learning rate of $10^{-2}$ and a batch size of $64$ for $175$ epochs until it stops improving. A loss plot for training the transformation matrix for our GloVe embeddings can be seen on figure \ref{fig:glove_loss}.
\begin{figure}[H]
    \centering
    \includegraphics[width=0.5\linewidth]{data_and_figs/glove_loss_plot.png}
    \caption{Plot of GloVe transformation matrix loss during training}
    \label{fig:glove_loss}
\end{figure}
The transformed embeddings for both Word2Vec and GloVe are however quite bad and generate seemingly random output, although it is still mostly coherent speech. This leads us to believe that there is no approximate linear transformation between the Word2Vec / GloVe embeddings and the MADLAD embeddings which have been trained through masked language modeling. Two example outputs can be seen on figure \ref{fig:embedding_examples}.

\subsection{\textsc{SMOL} finetuning}
We finetune with a learning rate of $5 \cdot 10^{-5}$ and a batch size of $8$ with a weight decay of $0.01$ using a A100 GPU on Google Colab. After $1$ epoch ($784$ steps) the model starts to overfit, and no longer improves on the test set, as can be seen on figure \ref{fig:finetuning_loss}, so we use a checkpoint of the model saved after the first epoch. The average BLEURT scores for the fine-tuned model on the test set with 95\% confidence intervals can be seen on figure \ref{fig:confidence_intervals}. We see an improvement of $0.044$ ($6.46\%$) BLEURT from the baseline model to the finetuned model.
